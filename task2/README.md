Task 2: Heap Sorting
Overview
This program uses maximum heap to implement heap sorting algorithm. It sorts 50 random integers and clearly displays each step of the sorting process.
operating principle
Generate 50 random numbers
Build the maximum stack based on numbers
Repeatedly extract the largest element and rebuild the heap
Output the final sorted list in descending order
feature
Display each sorting step: maximum extracted value, remaining elements, and sorting progress
Print the final sorting result
Console output is simple and easy to read
How to Run
Run Python scripts. The program will automatically generate numbers and start sorting.
